# Twitter Sensitive Media Loader
Chrome extension loading hidden sensitive medias of tweet using fxtwitter api

Download the project and load it using developer mode (https://developer.chrome.com/docs/extensions/get-started/tutorial/hello-world#load-unpacked)

You will need to click on the extension everytime you reload a page! Might change that later tho but it works rn sorry! :b

Scroll a bit and the button should pop up, click on it and the medias should pop below the tweet. Images are non interactive but you can still download them. You can also download videos!
