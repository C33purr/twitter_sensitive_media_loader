# Twitter Sensitive Media Loader
Chrome/Mozilla extension loading hidden sensitive medias of tweet using fxtwitter api
You will need to click on the extension everytime you reload a page! Might change that later tho but it works rn sorry! :b
Scroll a bit and the button should pop up, click on it and the medias should pop below the tweet. Images are non interactive but you can still download them. You can also download videos!

## Installation
Download the version for your browser and follow the tutorials below! :)
https://github.com/C33purr/twitter_sensitive_media_loader/releases/tag/V1.0

### Chrome

Download the project zip, unzip it and load the chrome folder using developer mode (https://developer.chrome.com/docs/extensions/get-started/tutorial/hello-world#load-unpacked)


### Mozilla

Download twitter_sensitive_media_loader_mozilla.xpi and install it on your browser (https://extensionworkshop.com/documentation/publish/install-self-distributed/ > Install add-on from file on a computer)
